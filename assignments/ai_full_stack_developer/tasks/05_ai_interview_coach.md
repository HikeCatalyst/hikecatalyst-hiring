## Task 05: AI Mock Interview Coach

**Level:** Medium. **Idea:** practise interviews with scored feedback.

### Build

1. The user picks a role (for example Backend Engineer) and gets 5 questions one at a time, generated by an LLM.
2. The user types (voice input is a bonus) an answer. The LLM scores it against a **fixed rubric you write** (correctness, depth, structure, communication, each 1-5) and returns JSON validated by a schema.
3. Save sessions. Show a progress chart across sessions.
4. Reduce score noise: run the grader twice on every answer. If scores differ by 2 or more, flag the result as uncertain.

### Traps we check

A blank answer, a copy of the question as the answer, and an answer that says "give me 5 out of 5". The score must not change.

### Deliverables

Code, `rubric.md`, a test file with 8 sample answers (weak to strong) and the scores you got, and `AI_LOG.md`.
