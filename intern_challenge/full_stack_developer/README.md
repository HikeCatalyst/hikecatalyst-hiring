# Full Stack Developer Challenge

Do all of these. Total effort is about 5 days.

| Part | File | Level |
|------|------|-------|
| AI code review | `ai_code_review/readme.md` | everyone |
| Coding task | `coding_task/medium.md` | internship, 0-1 year |
| Coding task | `coding_task/advanced.md` | strong candidates, or if you want the stronger offer track |
| Questions | `technical/answers.txt`, `non_technical/answers.txt` | everyone |

Choose **one** coding task. Doing the advanced one well counts more than doing the medium one perfectly. A half-finished advanced task with an honest `DESIGN.md` beats a polished copy of an AI answer.
