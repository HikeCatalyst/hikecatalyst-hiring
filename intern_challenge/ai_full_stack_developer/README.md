# AI Applied Full Stack Developer Challenge

You build real apps that use LLMs, and you must show you can handle what goes wrong with them. Total effort is about 5 days.

## What to do

1. **Everyone:** the AI code review (`ai_code_review/`), 45 minutes.
2. **Everyone:** the question files in `technical/` and `non_technical/`.
3. **Pick coding tasks from `tasks/`:**
   - Internship level: **one medium task**.
   - Stronger candidates: **one advanced task**, or one medium plus a second one of any level.

| # | Task | Level |
|---|------|-------|
| 01 | Resume Match Tracker | Medium |
| 02 | Application Pipeline with Async AI Jobs | Advanced |
| 03 | RAG Career Assistant with Citations | Medium |
| 04 | Text-to-SQL Analyst with Guardrails | Medium to Advanced |
| 05 | AI Mock Interview Coach | Medium |
| 06 | LLM Gateway | Advanced |
| 07 | Support Chatbot with Guardrails | Medium |
| 08 | Tool-Calling Job Search Agent | Advanced |
| 09 | MCP Server for a Candidate Tracker | Medium |
| 10 | Evaluation Harness for an LLM Feature | Advanced |
| 11 | Resume Rewriter with Fact Protection | Medium |
| 12 | Resume Parser with Human Review | Medium |

Different candidates get different tasks. We assign the task, so two candidates cannot share one answer.

## Rules

- AI tools are welcome. Log them in `AI_LOG.md` (prompts, what was wrong, what you fixed).
- Every task has traps. Finding them is part of the grade.
- Each submission has a README with setup steps, a `.env.example`, and honest notes on what does not work.
- A half-finished advanced task with an honest `DESIGN.md` beats a polished copy of an AI answer.
- In the 30-minute follow-up call you explain one file, break it on purpose, and add a change live.
